# 集装箱

## 项目概述

集装箱是一款集成了多种文档处理功能的实用工具，支持批量格式转换、内容统计、术语高亮、修订标记等操作。通过自动化处理 Word 和 PDF 文档，大幅提升办公效率。

## 主要特性

### 📄 文档处理
- **比较 Word** — 批量比较两个版本的 Word 文档
- **高亮修订** — 高亮标记文档中的修订内容
- **取消隐藏** — 取消 Word 中的所有隐藏格式
- **中文预编** — 自动隐藏不包含中文的段落
- **导出 Excel** — 将 Excel 中所有内容导出至 Word

### � 格式转换
- **存为低版本** — 批量将 docx 转为 doc
- **存为高版本** — 批量将 doc 转为 docx
- **存为纯文本** — 批量将 Word 转为 txt
- **存为 PDF** — 批量将 Word 转为 PDF

### 📊 文档统计
- **统计页数** — 提取文档页数
- **统计字数** — 统计 Word 文档字数
- **统计字符数** — 统计 Word 文档字符数（不计空格）

### 📦 批量整理
- **添加编号** — 为目录下所有文件添加前缀编号
- **删除编号** — 删除目录下所有文件开头编号
- **整理译文** — 按原文目录结构自动整理译文文件（基于文件名前缀编号）
- **项目明细表** — 生成包含目录结构的 Excel 明细表

### 🛠 实用工具
- **特殊字符表** — 方便地复制特殊字符
- **切换大小写** — 切换英文字母大小写或跳转至网页翻译

## 前置条件

- Windows 操作系统
- 已安装 Microsoft Word（支持 VBA 自动化）

## 更新日志

### 2026年5月7日更新说明 0.2.0
- 新增「整理译文」功能
  - 按原文目录结构自动整理译文文件
  - 基于文件名前缀编号（如 `001--xxx`）建立原文与译文的对应关系
  - 依次选择原文目录 → 译文目录 → 输出目录，三步完成整理
  - 自动生成「整理报告.txt」，包含完整性对比和缺失编号统计
  - 只复制不修改源文件，不覆盖已存在的目标文件
- 重构按钮分组，调整为五个功能组
  - **文档处理**（比较 Word、高亮修订、取消隐藏、中文预编、导出 Excel）

  - **文档统计**（统计页数、字数、字符数）
  - **批量整理**（添加/删除编号、整理译文、项目明细表）
