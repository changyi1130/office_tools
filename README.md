# 集装箱

一个功能强大的 Word 文档批量处理工具箱，旨在简化文档的日常管理与编辑工作。

## 项目概述

集装箱是一款集成了多种文档处理功能的实用工具，支持批量格式转换、内容统计、术语高亮、修订标记等操作。通过自动化处理 Word 和 PDF 文档，大幅提升办公效率。

## 主要特性

- **文档格式转换**
  - 批量将 Word 文档另存为 PDF
  - 高低版本 Word 格式互转 (doc ↔ docx)
- **内容分析与统计**
  - 提取文档页数
  - 统计字数与字符数（不计空格）
  - 获取文档目录结构
- **文档审阅与标记**
  - 批量比较 Word 文档（类似 Word 审阅功能）
  - 高亮标记修订内容
  - 基于频率和长度标记高频词
  - 自定义术语高亮（支持导入术语表）
- **文档优化与检查**
  - 检查文档字体使用情况
  - 检查文件名合规性
  - 取消 Word 所有隐藏格式
  - 美化统计类功能导出的 Excel 格式
- **文件管理**
  - 批量添加或删除文件名编号
  - Word 转纯文本

## 前置条件

- Windows 操作系统
- 已安装 Microsoft Word（支持 VBA 自动化）
